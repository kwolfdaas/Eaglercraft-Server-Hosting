Eagler.host — Free Eaglercraft Server Hosting
Eagler.host is a fast, lightweight, browser‑based hosting platform built specifically for Eaglercraft servers. It lets anyone create and manage a Minecraft‑style multiplayer server without port forwarding, without a VPS, and without installing Java. Everything runs in the cloud, and everything is controlled from your browser.

🚀 Features
Instant Deployment — Create a server in seconds with no setup required.

Web‑Based Console — Full live console with logs, commands, and server control.

Plugin Support — Upload .jar plugins directly from your browser.

File Manager — Edit configs, upload worlds, and manage server files.

Always‑Online Hosting — Your server stays up even when your device is off.

Beginner‑Friendly — No coding, no terminal, no complicated setup.

📦 Supported Versions
Eagler.host currently supports:

Eaglercraft 1.8.8

Eaglercraft 1.5.2

EaglercraftX 1.8

More versions are added as the community updates.

🛠️ How It Works
Eagler.host runs a custom backend designed to emulate a Minecraft‑like server environment inside the cloud. When you create a server:

A container is spun up with your selected Eaglercraft version.

Your world, plugins, and configs are loaded.

A unique WebSocket server address is generated.

Players join using any compatible Eaglercraft client.

This makes hosting extremely fast and accessible — perfect for schools, friends, or public communities.

📁 Plugin Support
Eagler.host includes a built‑in plugin installer that supports:

EssentialsX

LuckPerms

WorldEdit

Custom Plugins (upload your own .jar)

Just drag‑and‑drop your plugin into the panel — no FTP required.

🌐 Connecting to Your Server
Players can join using any Eaglercraft client by entering your server’s:

Code
wss://your-server.eagler.host
You can share this link publicly or keep it private for friends.
